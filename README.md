# Final Exams Table

A semantic HTML table displaying calculus final exam grades, built as part of the **freeCodeCamp Responsive Web Design** curriculum.

## About

This project demonstrates how to structure and organize tabular data using semantic HTML elements.

The table displays students' last names, first names, and final exam grades, along with the calculated average grade.

## Features

* Table caption
* Table header using `<thead>`
* Table body using `<tbody>`
* Table footer using `<tfoot>`
* Header cells using `<th>`
* Data cells using `<td>`
* Column spanning with `colspan`

## HTML Concepts Practiced

* `<table>`
* `<caption>`
* `<thead>`
* `<tbody>`
* `<tfoot>`
* `<tr>`
* `<th>`
* `<td>`
* `colspan`
